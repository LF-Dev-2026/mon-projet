# 🚀 Mon Premier Projet Web : Mon-projet

Ceci est mon tout premier site web hébergé sur GitHub Pages ! J'ai appris à structurer une page en HTML et à la styliser avec CSS (notamment en utilisant Flexbox).

## 🌐 Démo en ligne
Tu peux voir le résultat ici : **github.com/LF-Dev-2026**

## 🛠️ Technologies utilisées
*   **HTML5** : Pour la structure du site.
*   **CSS3** : Pour le design (Utilisation de `display: flex`, `gap`, etc.).
*   **GitHub Pages** : Pour l'hébergement gratuit.

## 📸 Aperçu
> [!TIP]
> *Ajoute une capture d'écran de ton site ici en faisant un glisser-déposer de l'image dans l'éditeur de GitHub.*

## 🧠 Ce que j'ai appris
- Comment organiser des éléments avec **Flexbox**.
- Comment rendre un dépôt public et utiliser la **Danger Zone** pour gérer mes projets.
- Comment déployer un site en ligne via GitHub.
